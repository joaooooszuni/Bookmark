Clube de Leitura Acadêmico com Progresso Sincronizado

Desenvolva uma plataforma para organizar a leitura conjunta de livros técnicos ou de ficção científica ao longo do semestre. Após o login via Discord OAuth2, os membros inscrevem-se no livro da rodada atual e atualizam regularmente a página ou capítulo em que se encontram, gerando uma pista visual em CSS com os avatares do Discord posicionados proporcionalmente ao avanço de cada leitor. O sistema conta com fóruns de discussão divididos por capítulos no Cloudflare D1, aplicando uma trava anti-spoiler no backend: uma Cloudflare Function só retorna as mensagens e análises de um determinado capítulo se o registro de progresso atual daquele usuário no banco de dados for igual ou superior ao capítulo que ele está tentando visualizar.
